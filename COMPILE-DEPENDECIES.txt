City of the Damned depends on the following Common Lisp libraries:
 - BORDEAUX-THREADS
 - CFFI
 - DEFENUM
 - CL-STORE
 - UIOP
 - LOG4CL

You may download and install them using Quicklisp.

The game also needs the SDL2 runtime library itself (libSDL2 / SDL2.dll), version 2.0.5 or newer - see COMPILING.txt. There is no Lisp binding for it in the list above on purpose: the game declares the library to CFFI itself and opens it on startup, so SDL2 has to be present to run the game, but not to compile or build it.
