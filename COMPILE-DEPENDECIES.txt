City of the Damned depends on the following Common Lisp libraries:
 - SDL2 (cl-sdl2)
 - BORDEAUX-THREADS
 - CFFI
 - DEFENUM
 - CL-STORE
 - UIOP
 - LOG4CL

You may download and install them using Quicklisp.

The game also needs the SDL2 runtime library itself (libSDL2 / SDL2.dll), version 2.0.5 or newer - see COMPILING.txt.
